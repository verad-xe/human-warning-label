The funniest single-line safety warning label that should come printed on every human being. Entry for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty.

The label:

> WARNING: This human will say "I'm five minutes away" for up to forty minutes. Do not plan around this estimate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/human-warning-label-out python3 main.py
```

This writes the one-line label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (111 characters, within the 160-character limit).
